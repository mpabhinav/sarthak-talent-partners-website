# Brand assets

Prepared from the client's two logo PNGs (`original-mark.png` and `original-lockup.png`, kept here as the source). Colours are the client's navy and gold, matched by the site palette (navy `#041838`, gold `#D7A449`).

| File | Use |
|---|---|
| `sarthak-mark.png` | The S mark with the figure and star, transparent. Footer, 404, pull quotes, JSON-LD `logo`. |
| `sarthak-mark-reversed.png` | Same with the navy parts turned white, for navy backgrounds. |
| `sarthak-lockup-horizontal.png` | Mark + SARTHAK / TALENT PARTNERS, tagline removed. Header logo. Render 48 px tall on mobile, 56 px from md up (source is 480 px, crisp at 2x+). |
| `sarthak-lockup-horizontal-reversed.png` | White version for the footer and mobile menu. |
| `sarthak-lockup-full.png` / `-reversed.png` | Full logo with "People. Growth. Success." Large placements only (About page, share image). |
| `favicon.ico`, `icon-192.png`, `icon-512.png`, `apple-icon.png` | App icons built from the mark. |
| `og-default.png` | Fallback 1200×630 share image (navy + reversed full logo). |
| `original-mark.png`, `original-lockup.png` | Client originals, reference only. Don't ship. |

Rules: never recolour, rotate, stretch, add effects to, or animate the logo. Keep clear space around the mark at least the height of the figure's head. Minimum size: mark 24 px, horizontal lockup 40 px tall (the TALENT PARTNERS line gets too small below that).

The logos are raster. If the client has the original vector files (AI/EPS/SVG/PDF), swap them in.
